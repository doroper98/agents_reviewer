Case Study
같은 시스템, 완전히 다른 분석

전략 기획 에이전트가 주제를 파악하고, 각 에이전트에게 맞춤 분석 지시를 내림. 동일한 7개 에이전트가 주제에 따라 완전히 다른 관점으로 분석함.

Case A
이란 전쟁의 한국 경제 영향
이란 전쟁의 장기화에 따라 한국 경제는 어떤 영향을 받게 되는지, 채권금리, 부동산, 환율, 주가는 어떻게 움직이게 될지 케이스 스터디 해
→ 이해관계자 분석관
"에너지 수출국(이란·사우디·러시아)과 수입국(한국·일본·대만) 중심으로 분석. DIME 프레임워크 적용"
→ 구조 분석관
"호르무즈 해협 공급망 병목 + 대체 경로 관점. Transmission Channel 기법으로 유가→물가→금리→환율 전이 경로 추적"
→ 연쇄반응 분석관
"에너지 가격 → 한국 CPI → 한은 기준금리 → 부동산/채권/원화 연쇄 충격 경로. Input-Output 분석 병행"
→ 시나리오 설계관
"호르무즈 봉쇄 기간별(30일/90일/180일) 시나리오. Stress Test 기법 적용"
geopolitical 에이전트 7/7 가동 DIME + Stress Test
Case B
Oracle의 엔터프라이즈 AI 전략과 클라우드 벤더 종속성
Oracle Exadata X11M 출시와 AI 통합 전략이 엔터프라이즈 시장에 미치는 영향을 분석해
→ 이해관계자 분석관
"기술 벤더(Oracle/AWS/MS/Google) 간 시장점유율과 플랫폼 종속 전략 비교. Network Analysis 적용"
→ 구조 분석관
"전환비용(switching cost)과 기술적 진입장벽 관점. 게임이론 아닌 독점 구조와 플랫폼 경제학으로 분석"
→ 연쇄반응 분석관
"가격 인상 → 고객 종속 심화 → 대안 검토 → 전환 실패 사이클 추적"
→ 시나리오 설계관
"오픈소스 대안 성장 속도별 시나리오. Cone of Plausibility 기법"
tech 에이전트 7/7 가동 Network + Cone of Plausibility

Pipeline Detail
내부 파이프라인 상세

한 건의 분석 요청이 시스템 내부에서 처리되는 과정. 각 에이전트는 독립된 Claude CLI subprocess로 실행됨.

0s
Telegram Webhook 수신
사용자 메시지 파싱 → 분석 큐 등록
telegram_bot.py → orchestrator.run_analysis()
~2s
상황 분석관 Sonnet
WebSearch + WebFetch로 최신 팩트 수집
claude -p "{system_prompt}\n{context}"
--allowedTools "WebFetch,WebSearch"
→ ContextAnalysis (JSON)
~90s
전략 기획 Opus
25+ 분석 기법 레퍼런스에서 최적 선택
Input: event_name + category + summary
Output: {
  "players": "DIME 프레임워크 적용...",
  "dynamics": "Transmission Channel...",
  "theme": "geopolitical",
  "skip": []
}
~150s
에이전트 순차 실행
각 에이전트가 전략 지시를 system prompt에 주입받아 실행
=== 전략 지시 (최우선 준수) ===
"{directive}"
위 지시에 따라 분석 관점과 기법을 조정할 것.
===

players → dynamics → chain → scenarios
(각각 독립 subprocess, 이전 결과 입력)
~600s
시각화 분석관 Opus
전략 지시에 따라 필요한 시각화만 선택 생성
SVG 관계도: 필요 시에만
Leaflet 지도: 지리적 요소 있을 때만
Canvas 차트: 수치 데이터 있을 때만
→ VisualAnalysis (JSON + SVG)
~750s
보고서 합성관 Sonnet
내러티브 구조 결정 + HTML 렌더링 + Cloudflare 배포
asyncio.gather(
  executive_summary(),  # 거버넌스 + 핵심요약
  narrative_plan()     # 섹션 순서·제목 결정
)
→ Jinja2 template + data-theme="{theme}"
→ wrangler pages deploy --branch main
→ https://analysis-reports.pages.dev/{file}
~800s
결과 전달
텔레그램으로 텍스트 요약 + 보고서 링크 전송
