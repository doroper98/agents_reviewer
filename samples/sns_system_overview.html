Analysis Sequence
분석 시퀀스
1
분석 요청
텔레그램에 주제를 자연어로 입력. "짧게" 키워드로 빠른분석 모드 가능
2
상황 파악
상황 분석관이 웹 검색으로 최신 팩트·타임라인·핵심 수치 수집
3
전략 기획
Opus가 25+ 분석 기법 중 최적 기법 선택, 각 에이전트에 맞춤 지시, 보고서 테마 결정, 불필요한 에이전트 스킵
4
전문 분석
각 에이전트가 전략 지시에 따라 고유 관점으로 분석. 이전 에이전트 결과를 반영한 점진적 심화
5
시각화
SVG 관계도, 지도, Canvas 차트 등 — 주제에 필요한 시각 요소만 선택적 생성
6
보고서 생성
동적 내러티브 구조로 HTML 보고서 렌더링, Cloudflare에 즉시 배포, 공유 링크 전달
