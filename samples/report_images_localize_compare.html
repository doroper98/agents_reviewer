① 수집
image URL 모으기

② 다운로드
병렬 fetch + 매체 Referer
매체 자기 도메인을 Referer 로 송신해 CDN 검사 통과. 파일명 = SHA256(URL)[:16] + 자동 확장자, 같은 URL dedup.
③ 저장
reports/img/ 에 기록
12MB cap, 1KB 미만 placeholder 거름. 1주 캐시 (이미 있으면 skip). Cloudflare 가 reports/ 통째로 업로드 → 자동으로 함께 배포.

composed_report URL 치환
