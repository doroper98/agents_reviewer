★ v7.1.0 에서 production 이식 완료 (사용자 승인, 발행본 소급). 좌측 카드도 production charts.js 를 로드하므로 이식 후엔 양쪽이 같은 (신규) 디자인으로 보인다 — 이식 전 비교가 필요하면 git 이력의 v7.0.2 시점 charts.js 를 참조.

bar / donut / stacked / bubble / heatmap / network / waterfall — 초창기에 추가돼 디자인 어휘가 오래된 7종의 리디자인 제안. 좌측이 production 현행, 우측이 리디자인 (같은 데이터). mono 테마 제약 (단일 액센트 · 45° 단방향 해치 · 다색 금지) 은 유지하되, 카테고리 구분이 아닌 곳의 해치 노이즈를 걷어내고 단일 색조의 농도 위계 + 세리프 숫자 + 직접 라벨링으로 교체했다.

병합 제안 — ① stacked 는 bar 와 같은 "가로 막대 문법" 으로 통일 (type·데이터 계약은 그대로, 시각 어휘만 패밀리화). ② heatmap 과 network(인접행렬) 는 같은 셀-그리드 엔진을 공유. ③ donut 은 유지하되 "핵심 1조각" 강조 문법으로 — 구성비의 주인공이 한눈에.
