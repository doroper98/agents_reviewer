# Event Analysis Team - 팀 설계 문서

## 1. 팀 구성 (9 Agents)

### Core Layer: 지휘/조율

#### 1) Orchestrator (오케스트레이터)
- **역할**: 전체 분석 프로세스 지휘, 태스크 분해 및 분배
- **핵심 역량**: 태스크 라우팅, 의존성 관리, 타임라인 관리
- **입력**: 텔레그램으로부터 수신된 사용자 명령
- **출력**: 각 에이전트에 대한 구조화된 분석 요청

### Identification Layer: 사건 식별

#### 2) Event Identifier (사건 식별자)
- **역할**: 사건의 정확한 정의, 핵심 팩트 수집, 소스 검증
- **핵심 역량**: 정보 수집(웹/뉴스/API), 팩트체크, 1차/2차 소스 구분
- **입력**: 사건명 또는 키워드
- **출력**: 구조화된 사건 프로필 (5W1H + 관련 데이터)

### Analysis Layer: 4대 파급력 분석

#### 3) Macro Analyst (거시경제 분석가)
- **역할**: 거시경제적 파급력 분석
- **분석 항목**:
  - GDP/경제성장률 영향
  - 통화정책/금리 변동 가능성
  - 인플레이션/디플레이션 압력
  - 국제무역/환율 영향
  - 재정정책 변화 가능성

#### 4) Geopolitical Analyst (지정학 분석가)
- **역할**: 지정학적 파급력 분석
- **분석 항목**:
  - 관련국 간 관계 변화
  - 제재/무역 규제 가능성
  - 군사/안보 리스크
  - 에너지/자원 공급망 영향
  - 지역 안정성 평가

#### 5) Micro Analyst (미시경제 분석가)
- **역할**: 미시경제적 파급력 분석
- **분석 항목**:
  - 영향받는 산업/섹터
  - 기업 실적/매출 영향
  - 소비자 행동 변화
  - 공급망/가격 구조 변화
  - 경쟁 구도 변화

#### 6) Investment Analyst (투자 분석가)
- **역할**: 투자 관점 파급력 분석
- **분석 항목**:
  - 자산군별 영향 (주식/채권/원자재/암호화폐/부동산)
  - 섹터 로테이션 전략
  - 리스크/리턴 프로파일 변화
  - 헤지 전략 제안
  - 단기/중기/장기 투자 시나리오

### Context Layer: 역사/윤리적 맥락

#### 7) Historian & Ethics Analyst (역사/윤리 분석가)
- **역할**: 역사적 유사 사례 분석 + 도덕적/윤리적 판단
- **분석 항목**:
  - 역사적 유사 사건 식별 (최소 3개)
  - 과거 사건의 전개 패턴과 결과
  - 현재 사건과의 유사점/차이점
  - 윤리적 프레임워크 적용 (공리주의, 의무론, 덕윤리)
  - 사회적 정의 및 형평성 관점
  - 장기적 사회/문화적 영향

### Audit Layer: 검증/감사

#### 8) Devil's Advocate (비판적 검증자 / 감사역)
- **역할**: 모든 분석의 품질 감사, 편향 검출, 반론 제시
- **핵심 역량**:
  - 각 분석의 논리적 일관성 검증
  - 확증편향/생존자편향 등 인지편향 탐지
  - 대안 시나리오(Counter-factual) 제시
  - 데이터 신뢰도 평가
  - 분석 간 모순점 식별
- **입력**: 모든 에이전트의 1차 분석 결과
- **출력**: 검증 보고서 + 수정 요청

### Output Layer: 보고서 생성

#### 9) Report Synthesizer (보고서 합성자)
- **역할**: 최종 비주얼 보고서 생성
- **핵심 역량**:
  - 차트/그래프 생성
  - 인포그래픽 디자인
  - Executive Summary 작성
  - 핵심 수치/지표 하이라이트
- **출력 형식**: HTML 보고서 + 텔레그램 요약 메시지

## 3. Devil's Advocate (감사역) 상세 프로세스

```
┌─────────────────────────────────────────────┐
│          AUDIT CHECKLIST                     │
├─────────────────────────────────────────────┤
│                                             │
│  □ 논리적 일관성 (Logical Consistency)       │
│    - 전제 → 결론의 논리 흐름 검증            │
│    - 순환 논증 여부 확인                     │
│                                             │
│  □ 인지 편향 검출 (Cognitive Bias Detection) │
│    - 확증편향 (Confirmation Bias)            │
│    - 생존자편향 (Survivorship Bias)          │
│    - 최신편향 (Recency Bias)                 │
│    - 앵커링효과 (Anchoring Effect)           │
│                                             │
│  □ 데이터 품질 (Data Quality)                │
│    - 소스 신뢰도 등급 (A/B/C/D)             │
│    - 데이터 최신성 확인                      │
│    - 샘플 크기/대표성 검증                   │
│                                             │
│  □ 대안 시나리오 (Counter-factual)           │
│    - 최소 2개의 대안 시나리오 제시            │
│    - "만약 ~라면?" 질문 적용                 │
│                                             │
│  □ 분석 간 교차 검증 (Cross-validation)      │
│    - 에이전트 간 결론 모순 확인              │
│    - 상충하는 예측 식별 및 조정              │
│                                             │
│  판정: PASS / REVISE(부분수정) / REJECT(재분석)│
└─────────────────────────────────────────────┘
```
