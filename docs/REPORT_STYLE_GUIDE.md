## 1. 색상 팔레트

### 배경
| 용도 | 색상 | HEX |
|------|------|-----|
| 메인 배경 | 다크 마룬 | `#2B1A1A` |
| 카드/박스 배경 | 살짝 밝은 마룬 | `#3D2828` |
| 강조 카드 배경 | 중간 마룬 | `#4A3232` |

### 텍스트
| 용도 | 색상 | HEX |
|------|------|-----|
| 제목/헤딩 (H1, H2) | 웜 크림 | `#F0E2CC` |
| 본문 텍스트 | 밝은 크림 | `#D4C4AA` |
| 보조/설명 텍스트 | 뮤트 크림 | `#A89880` |
| 비활성/캡션 | 페이드 브라운 | `#7A6E5E` |

### 강조/기능색
| 용도 | 색상 | HEX |
|------|------|-----|
| 골드 강조 (활성, 하이라이트) | 골드 | `#C9A84C` |
| 골드 테두리 | 밝은 골드 | `#D4B45C` |
| 위험/경고 | 따뜻한 레드 | `#C45C4C` |
| 긍정/안전 | 뮤트 그린 | `#6B8A5C` |
| 정보/중립 | 뮤트 블루 | `#5C7A8A` |

### 선/구분선
| 용도 | 색상 | HEX |
|------|------|-----|
| 수평 구분선 | 뮤트 그레이 크림 | `#6B5F50` |
| 카드 테두리 | 연한 크림 | `#5A4A3A` |
| 골드 테두리 (강조 카드) | 골드 | `#C9A84C` |

## 2. 타이포그래피

### 폰트 패밀리
| 용도 | 폰트 | 웨이트 |
|------|------|--------|
| 제목 (한글) | Noto Serif KR | 900 (Black) |
| 제목 (영문) | Noto Serif KR 또는 시스템 산세리프 | 900 |
| 본문 (한글) | Noto Sans KR | 400 (Regular) |
| 라벨/캡션 | Noto Serif KR | 400 Italic |
| 코드/데이터 | Noto Sans KR | 500 |

### 폰트 크기
| 요소 | 크기 | 스타일 |
|------|------|--------|
| 히어로 제목 | clamp(24px, 6vw, 42px) | 900, uppercase 가능 |
| 섹션 제목 | clamp(18px, 4vw, 28px) | 900 |
| 섹션 라벨 | 10px | italic, letter-spacing 1px |
| 본문 | 14px | 400, line-height 1.8 |
| 보조 텍스트 | 12px | 400, line-height 1.7 |
| 캡션/각주 | 10px | 400 |
| 데이터/수치 | 14~16px | 700 |

### 텍스트 규칙
- 제목: 대문자 가능하지만 한글은 그대로
- 본문: 소문자 스타일, 마침표로 끝남
- 라벨: 이탤릭 세리프 ("ACT I — THE BOARD" 형태)
- 숫자/데이터: 굵게(bold), 크림색 또는 골드

## 3. 레이아웃

### 페이지 구조
```
┌─────────────────────────────────┐
│  히어로 (다크 마룬 배경)           │
│  제목 + 서브타이틀 + 태그          │
├─────────────────────────────────┤
│  네비게이션 (스티키, 반투명)        │
├─────────────────────────────────┤
│  섹션 반복:                      │
│    라벨 (이탤릭, 뮤트)             │
│    다이어그램/카드/테이블           │
│    ─── 얇은 수평 구분선 ───       │
│    섹션 제목 (굵은 크림)           │
│    본문 텍스트                    │
├─────────────────────────────────┤
│  푸터 (다크 마룬, 뮤트 텍스트)     │
└─────────────────────────────────┘
```

### 간격
| 요소 | 값 |
|------|-----|
| 컨테이너 max-width | 960px |
| 섹션 패딩 (상하) | 40px ~ 48px |
| 카드 패딩 | 16px ~ 20px |
| 카드 간 간격 | 10px ~ 12px |
| 구분선 상하 마진 | 24px |

## 4. 컴포넌트

### 카드
- 배경: `#3D2828` (메인 배경보다 살짝 밝은 마룬)
- 테두리: 1px solid `#5A4A3A`
- 모서리: 6~8px radius
- 그림자: 없음 (플랫)
- 강조 카드: 골드 테두리 `#C9A84C`

### 수평 구분선
- 1px solid `#6B5F50`
- 너비: 100% 또는 80% 중앙 정렬
- 구분선 위에 콘텐츠, 아래에 제목+본문

### 배지/태그
- 배경: `#4A3232`
- 텍스트: 해당 기능색 (위험=레드, 긍정=그린)
- 테두리: 1px solid 해당 색상
- 크기: 8~9px, padding 2px 8px
- 라운딩: 3px

### 테이블
- 헤더: `#3D2828` 배경, 크림 텍스트
- 행 구분: 1px solid `#3D2828`
- 호버: `#4A3232`
- 텍스트: `#D4C4AA`

### 플로우 (연쇄반응)
- 노드: `#3D2828` 배경, 크림 테두리
- 화살표: 크림색 `#6B5F50`, 세로
- 심각도 표시: 왼쪽 3px 바 (위험=레드, 경고=오렌지, 기본=골드)

### 네비게이션
- 배경: `#2B1A1A` 90% opacity + backdrop-filter blur
- 링크: 뮤트 크림 `#7A6E5E`, 활성=크림 `#F0E2CC`
- 하단 인디케이터: 2px 골드 `#C9A84C`

## 5. SVG 다이어그램 (시각화 분석관용)

### 관계도
- 배경: transparent (HTML 배경 계승)
- 노드: fill `#3D2828`, stroke `#5A4A3A` 1px, rx 6~8
- 노드 텍스트: `#F0E2CC` (이름), `#A89880` (역할)
- 중앙 노드: fill `#2B1A1A`, stroke `#C9A84C` 2px (골드 강조)
- 연결선: stroke `#6B5F50` 1.5px, cubic bezier 곡선
- 활성 경로: stroke `#C9A84C` (골드)
- 화살표: 크림색 삼각형

### 플로우차트
- 노드 배경: 심각도별 색상
  - HIGH: `#C45C4C` (fill, 크림 텍스트)
  - MEDIUM: `#C9A84C` (fill, 어두운 텍스트)
  - LOW: `#3D2828` (fill, 크림 텍스트)
- 화살표: `#6B5F50`, 세로 직선

## 6. 차트 (Canvas 2D)

- 배경: transparent
- 그리드 선: `#3D2828`
- 축 텍스트: `#A89880`
- 데이터 선: `#C9A84C` (골드) 또는 `#D4C4AA` (크림)
- 데이터 포인트: `#F0E2CC`
- 툴팁 배경: `#3D2828`, 크림 텍스트

## 7. 톤앤매너 원칙

1. **어둡고 따뜻한 배경** — 차갑지 않은 다크 모드. 마룬/버건디 톤.
2. **크림색 타이포그래피** — 순백(#fff) 금지. 항상 따뜻한 크림.
3. **절제된 색상 사용** — 골드만 강조색, 나머지는 배경과 텍스트 톤 안에서.
4. **플랫 디자인** — 그림자 최소화, 테두리로 구분.
5. **넉넉한 여백** — 꽉 채우지 않음. 호흡감.
6. **다이어그램은 얇은 선** — 1~2px 크림/골드 선, 곡선 선호.
7. **구분선 아래 제목** — 콘텐츠 → 구분선 → 제목 → 본문 순서.
