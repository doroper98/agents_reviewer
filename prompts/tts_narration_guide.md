## 0. 가장 중요한 원칙 — 표기용(자막)과 발화용(음성)의 분리

영상은 **자막과 음성을 따로** 쓴다. 계약 §13 의 두 필드가 정확히 이 분리다.

| 필드 | 역할 | 규칙 |
|---|---|---|
| `narration` | **자막(표기용)** | 눈으로 읽는다. 숫자·영문 약어·`%` 를 *그대로 써도 된다* (예: "SK하이닉스가 7.68% 빠졌습니다"). 단 문장 자체는 구어체·짧은 연쇄여야 한다 (§1). |
| `narration_tts` | **음성(발화용)** | 귀로 듣는다. TTS가 틀리거나 어색하게 읽을 표기를 *사람이 말하는 형태로* 미리 바꿔 둔다 (예: "에스케이하이닉스가 칠 점 육팔 퍼센트 빠졌습니다"). |

> **★ 적용 범위 절대 경계 (v7.6.4 — 사용자 지적: 텔레그램 요약에 'WTI'가 '더블유티아이'로 나옴).**
> 아래 §2~§6 의 *발음 변환*(WTI→더블유티아이, D램→디램, %→퍼센트, 숫자→한글)은
> **오직 `narration_tts` / `*_narration_tts` 필드에만** 적용한다. **`broadcast_summary`
> (텔레그램 요약) · `prose`(본문) · `headline` · `deck` · `narration`(자막) · `highlights` ·
> timeline · contradictions** 같은 *눈으로 읽는 글* 에는 절대 적용하지 않는다 — 거기선
> 원래 표기 그대로(WTI · D램 · GPU · HBM · 7.86% · 8,000). 발음 표기는 성우가 읽는 음성
> 전용이고, 글에 쓰면 어색하다. producer 가 `narrative_composer._revert_phonetic_in_text`
> 로 `broadcast_summary` 의 명확한 약어 누수를 결정적 복원(더블유티아이→WTI 등) + 본문
> 누수를 warn 한다 (2중 방어, 1차는 본 경계 + composer SYSTEM_PROMPT).

**규칙:**
1. `narration` 의 한 문장이라도 TTS가 깨뜨릴 표기(아래 §2~§5)를 포함하면, 그 섹션은
   `narration_tts` 를 **반드시** 채운다. `narration_tts` 는 `narration` 과 *같은
   순서·같은 개수* 의 배열이다. 바꿀 게 없는 문장은 동일 문장을 그대로 둔다.
2. TTS가 깨뜨릴 표기가 *전혀 없는* 섹션(순한 한국어 문장만)은 `narration_tts` 생략 가능.
2-1. 보고서 레벨 `report.video` 의 intro/outro 도 동일하다 (v7.4.1) —
   `intro_narration_tts` / `outro_narration_tts` 를 같은 순서·개수로 채운다.
2-2. 타임라인 씬 `timeline.video` 도 동일하다 (v7.6.0, composer 는 `timeline_flow.video`
   로 emit) — `{narration, narration_tts}` 만 (highlights/emphasis 없음). narration 은
   분기점들을 *이야기로 잇는* 3~4문장 — 분기점 라벨 낭독 금지 (§1). 비우면 영상 쪽이
   기계 문장으로 메운다 (그게 1차 검수에서 어색하다고 잡힌 부분).
2-3. 쟁점 카드 `contradictions[].video` 도 동일하다 (v7.6.2). 영상이 `side_a`/`side_b`
   *논설체 원문* ("…정책 전환이다") 을 카드·자막에 그대로 노출하던 것을 다큐 경어체
   대본으로 대체. 형식: `{label_a, label_b, line_a, line_b, narration, narration_tts}`.
   - `label_a`/`label_b`: 두 입장의 진영 이름. 한 단어 명사구 ≤8자 (예: "묵인론"/"전술론").
   - `line_a`/`line_b`: 각 입장의 한 줄 요약, 경어체 ≤40자 (스테이트먼트 씬 — 카드에
     크게). "~입니다/~수도 있습니다" 로 끝낸다.
   - `narration`: 쟁점 씬 자막 2~3문장(경어체) + `narration_tts` (위험 표기 있으면).
   - `side_a`/`side_b` 원문은 그대로 두고 `video` 만 *더한다* (additive).
3. `emphasis` 는 *자막(`narration`/`highlights`)* 기준이다. `narration_tts` 가 아니다.
4. 자막과 음성의 *의미·수치·순서* 는 반드시 일치 — 자막은 "7.68%", 음성은 "칠 점
   육팔 퍼센트" 처럼 *표기만* 다르고 내용은 같아야 한다 (불일치는 즉시 어색함, §44).

## 1. 내레이션 문장 자체 규칙 (narration·narration_tts 양쪽 공통)

발음을 아무리 다듬어도 *문장이 AI가 쓴 티가 나면* 음성도 AI처럼 들린다.

- **★ 축약 금지 — 말하듯 풀어쓴다 (v7.6.0, 1차 검수 최우선 지적: "너무 축약해서
  대본이 써졌고 그걸 읽음").** narration 은 자막용 요약문이 아니라 **성우가 읽는
  구어체 대본**이다. 눈으로 읽는 글이 아니라 귀로 듣는 말로 쓸 것. 한 문장에
  정보 하나, 명사 나열 대신 주어-동사 문장.
  - 나쁨: "앤스로픽에 이어, 한 달 새 두 번째 메가 임대입니다."
  - 좋음: "앤스로픽과 계약한 지 한 달 만에, 두 번째 대형 임대가 나온 겁니다."
  - **길이 한도: 문장당 75자** (v7.6.0 — 풀어쓰기 위해 58→75 완화, 자막 줄바꿈은
    영상 쪽이 처리). 짧게 줄이려고 조사·서술어를 삭제하지 말 것.
- **★ 날짜·시간 표현 — 나열 금지, 조사로 연결 (v7.6.0).** "{날짜}, {문장}" 콤마
  나열은 어색하다 ("6월 5일, 앤스로픽이 뭘 했습니다" X). "{날짜}에는/{날짜}에
  ~했습니다" 로 연결한다.
  - 나쁨: "실제로 1월, 최대 100만 위성 규모를 신청했습니다."
  - 좋음: "실제로 1월에는 최대 100만 위성 규모를 신청했습니다."
- **★ 제목·라벨을 그대로 읽는 문장 금지 (v7.6.0).** 섹션 제목, 차트 제목,
  타임라인 분기점 라벨은 화면이 이미 보여준다. 내레이션이 그걸 따라 읽으면 안
  된다 — 내레이션은 그 내용을 "이야기"로 푼다.
  - 나쁨: "사건의 궤적, 흡수에서 임대, 그리고 궤도까지."
  - 좋음: "이 일이 어떻게 시작됐는지, 처음부터 따라가 보겠습니다."
- **★ highlights 가 heading 을 그대로 반복하지 말 것 (v7.6.2, 2차 검수).** heading 이
  "묵인이냐 침묵이냐" 인데 highlight 도 같은 문구면 화면에 같은 말이 두 번 뜬다.
  highlight 는 heading 이 *안* 보여준 구체 수치·고유명사를 담는다.
  - 나쁨: heading "묵인이냐 침묵이냐" / highlight "묵인이냐 침묵이냐"
  - 좋음: heading "묵인이냐 침묵이냐" / highlight "비핵화 표현 빠진 공동성명"
- **★ 가운뎃점(·)으로 항목 두 개를 붙이지 말 것 (v7.6.2, 2차 검수).** "김여정 담화·김정은
  핵물질 공장" 처럼 `·` 로 두 항목을 붙이면 화면에서 한 단어로 보이고 음성도 어색하다.
  조사로 풀거나, 부득이하면 ` · `(앞뒤 공백). narration·highlights·prose 공통.
  출처 나열(NPR·CBS) 같은 관용적 경우만 · 허용 (v7.6.3).
  - 나쁨: "김여정 담화·김정은 핵물질 공장"
  - 좋음: "김여정 부부장의 담화와 김정은 위원장의 핵물질 공장 시찰"
- **★ narration 각 항목은 완결된 한 문장 (v7.6.2, 2차 검수).** "…침묵보다" 처럼 비교·연결
  도중에 끊지 말 것 — 배열 한 항목이 곧 한 자막이라 중간 절단은 미완성 자막이 된다.
  - v7.6.3 강화: 비교·인용·접속 어미("…보다", "…때문에", "…위해")로 끝나는 절단 금지.
    주어-서술어가 한 문장 안에서 닫힌다 (화면 자막 한 cue = 한 완결 문장).
- **★ 무기 체계명 음차 표기 금지 → 영문 (v7.6.2, 2차 검수).** "장보고-엔"·"장보고 엔" →
  "장보고 N". headline/heading/highlights/prose 어디서나. (narration 의 발음은
  narration_tts 에서 "장보고 엔" 으로 — 표기는 영문, 발화는 한글 음.)
- **★ 부정·불가능 의존명사 "수 없는" 누락 금지 (v7.6.3, 3차 검수 — 이번 핵심).**
  부정 의미를 의도한 관형형이 빠져 의미가 뒤집히는 사고가 반복됐다. "절대로/결코" 가
  앞에 오면 거의 항상 "~할 수 없는" 이 필요하다. "물러설/양보할/넘을/되돌릴 + 한계선·
  선·지점·레드라인" 처럼 부정 의도면 "~할 수 없는" 을 반드시 넣는다.
  - 사고: "핵보유국 지위는 절대로 물러설 한계선이라고 못박았습니다."
  - 교정: "핵보유국 지위는 절대로 물러설 수 없는 한계선이라고 못박았습니다."
- **★ 종결어미는 다큐 경어체로 통일 (v7.6.3, 3차 검수).** narration·line 은 성우가 읽는
  대본이다. 논설체·반말("~이다/~한다/~했다")로 끝내지 말고 "~입니다/~합니다/~됩니다" 로
  닫는다. 특히 contradictions 의 side/resolution 을 narration·line 으로 옮길 때 —
  원문이 논설체이므로 *경어체로 다시 쓴다* (그대로 베끼지 말 것).
  - 나쁨: "베이징이 비핵화를 뺀 건 핵보유 묵인이다."
  - 좋음: "베이징이 비핵화를 뺀 건 핵보유 묵인입니다."
- **구어체로 쓴다.** 문어체 한자투("본 과제는…", "제고하고자", "상기 내용")를 금지.
  "이 과제의 목적은…", "높이려는 것", "앞서 말한 내용" 으로 푼다.
- **짧은 문장을 손잡게 잇는다.** 앞 문장이 던진 것을 다음 문장이 받는다. 서로 무관한
  사실을 차례로 늘어놓는 *나열* 금지 (그게 기계 템플릿과의 차이다). 단 너무 짧게만
  자르면 또 로봇처럼 끊긴다 — 한 문장 한 메시지가 기준.
- **AI 상투어 금지:** "결론적으로 말하자면", "다음은 세 가지 이유입니다", "중요한
  것은 바로 이것입니다", "~할 수 있습니다" 남발, 불필요한 주어 명시("우리는").
- **강조는 의미 단위에.** 비교문은 *대비되는 쪽* 에 무게("A가 아니라 **B**입니다").
  부정문은 *부정의 초점* 에("데이터가 없어서가 아닙니다"). 원인-결과는 결과를 선명하게.
- **쉼표를 줄인다.** 글보다 음성 대본은 쉼표가 적어야 한다 — TTS는 쉼표마다 기계적으로
  끊는다. 마침표만 찍힌 짧은 문장 3연속도 낭독처럼 딱딱하니, 둘은 자연스럽게 잇는다.
- **태도 일치.** 차분한 경어체(~입니다/했습니다/~겁니다). 감탄·유행어·수사적 질문·
  광고 톤·과장 금지. 무게는 단어가 아니라 사실에서 나온다.

## 2. 숫자 — 한국어 이중 체계 (가장 치명적인 AI 티)

한국어 숫자는 **고유어(하나·둘·셋)** 와 **한자어(일·이·삼)** 두 체계이고 문맥마다 갈린다.
TTS는 자주 틀린다. `narration_tts` 에서 *읽는 대로* 적어 고정한다.

**★ v7.6.0 (1차 검수 실사고) — 숫자는 전부 한글로, 자연 발음 단위로 띄어 쓴다.**
"32개월" → "삼십이 개월" (붙여 쓰면 "개"에 강세가 걸려 어색하게 읽힘 — 띄어쓰기
포함해 자연 발음으로), "7개" → "일곱 개". 아라비아 숫자를 narration_tts 에 남기지
말 것.

| 의미 | 계열 | 예 |
|---|---|---|
| 개수·명·번(횟수)·살·달·군데 | **고유어** | 세 개 / 두 명 / 세 번 / 한 달 / 다섯 군데 |
| 시각의 '시' | 고유어 | 두 시, 네 시 |
| 시각의 '분', 차수·번호·위·연도·금액·비율·분기 | **한자어** | 삼십 분 / 이차전지 / 일 번 / 일 위 / 이천이십육년 / 삼천 원 / 십 퍼센트 / 이분기 |

**반드시 지킬 대표 오류:**
- `2차전지` → **이차전지** (절대 "두 차 전지" 아님). `1위` → 일 위. `2분기` → 이분기.
- `3개` → 세 개. `2명` → 두 명. `1살` → 한 살. (개수·명·살은 고유어)
- 연도 `2026년` → 이천이십육년. 날짜 `5월 13일` → 오월 십삼일.
- **월 읽기 예외:** `6월` → **유월**, `10월` → **시월** (육월·십월 아님).
- 금액 `3,000원` → 삼천 원 (콤마를 "콤마"로 읽지 말 것). `1,200명` → 천이백 명.
- 소수 `7,634.76` → 칠천육백삼십사 점 칠육. `0.03%` → 영 점 영삼 퍼센트.
- 큰 단위 `150조원` → 백오십조 원. `21.7억 달러` → 이십일 점 칠억 달러.
  `1.75조 달러` → 일 점 칠오조 달러. `740억` → 칠백사십억.
- 배수 `두 배` 는 고유어(한 점 오 배 / 일점오 배는 소수일 때). `30%` → 삼십 퍼센트.

**부호:** 등락은 부호를 *말로* 푼다. `-7.68%` 를 "마이너스 칠…" 로 읽기보다 문장에서
"칠 점 육팔 퍼센트 **하락/빠졌습니다**" 로. `+12%` → "십이 퍼센트 상승". 추정치의
"약", 비교의 "전년 대비", 단위·기준일을 *빠뜨리지 말 것* (누락은 의미 왜곡, §36).

## 4. 기호 — 그대로 읽지 말고 의미로

| 기호 | 금지(그대로) | narration_tts |
|---|---|---|
| `/` | "슬래시" | 문맥따라 "와/또는/부터", 또는 생략 ("에이비 테스트") |
| `→` | "화살표" | "에서 …로" (14일→4일 = 십사일에서 사일로) |
| `~` | "물결" | "에서 …까지" / "부터 …까지" (3~5일 = 삼 일에서 오 일) |
| `:` | "콜론" | "대"(1:1=일대일, 16:9=십육 대 구) / 시각("아홉 시 삼십 분") / "은/는"으로 풀기 |
| `()` | "괄호" | 대개 생략. 설명형은 "즉/다시 말해/예를 들어" 로 풀기 |
| `%` | (OK) | 퍼센트 (또는 프로) |
| `±` | "플러스 마이너스" | "플러스마이너스 …" 또는 "… 내외" |
| `>` `<` | "그레이터/레스 댄" | "초과" / "미만" |
| `△▲▼` `↓↑` | 기호 낭독 | "감소/상승" 등 말로 |
| `-` (하이픈) | "하이픈" | 대개 생략하거나 단어로 (A-1 = 에이 원) |
| `※ • # @ []` | 기호 낭독 | "참고로 / (불릿 생략) / 1번 / 계정명은 자막 / 대괄호 생략" |

## 5. 읽지 말아야 할 것 / 자막으로 넘길 것

- **URL·이메일·파일명·경로·코드**는 음성으로 통째 읽지 않는다. "링크는 화면에서
  확인", "해당 파일", "이 설정" 으로 의미만. 정확한 문자열은 자막·QR.
- 페이지번호·각주·반복 헤더·파일 확장자는 대개 생략.
- 단, **단위·부호·기준일·전제·"약"·"목표"** 는 *건너뛰면 의미가 바뀐다* — 반드시 읽는다.
